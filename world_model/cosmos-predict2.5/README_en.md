## Overview of Cosmos-Predict2.5-2B
Paper Title: World Simulation with Video Foundation Models for Physical AI

## Functional Introduction
Cosmos-Predict2.5-2B is a state-of-the-art world foundation model released by NVIDIA, tailored for world simulation tasks within Physical AI scenarios. Built upon the Flow Matching architecture, it leverages Cosmos-Reason1, a vision-language model optimized for Physical AI, as the text encoder. It can generate high-quality videos that comply with physical laws, enabling precise simulation and prediction for complex dynamic scenarios such as robotic manipulation and autonomous driving.
The model is pre-trained on 200 million curated video clips covering robotic manipulation, autonomous driving, intelligent spaces, human motion and various physical phenomena. Reinforcement learning-based post-training further optimizes video quality and instruction alignment performance. On the PAI-Bench Physical AI benchmark, Cosmos-Predict2.5-2B achieves industry-leading performance on Text2World and Image2World tasks. Its overall evaluation scores are comparable to Wan2.2-27B-A14B, which has seven times the parameter scale.
It supports three conditional input modes: text, image and video, and can be flexibly deployed for tasks including synthetic data generation, policy evaluation, closed-loop simulation and multi-view camera control. It delivers outstanding performance in robotic policy learning, autonomous driving simulation, VLA model training data synthesis and other scenarios. A single video clip generated by the model lasts roughly 5.8 seconds. Segmented generation followed by concatenation supports long videos of 30–120 seconds with stable temporal consistency, demonstrating excellent temporal coherence and physical plausibility.

## Environment Configuration for Cosmos-Predict2.5-2B on Ascend A3
### Ascend Platform-Dependent Environment Setup
Install CANN software packages. Compilation and runtime execution of this sample rely on the CANN development toolkit (cann-toolkit) and CANN binary operator package (cann-kernels). The validated CANN version is `CANN 8.3.RC1`.

Download `Ascend-cann-toolkit-${version}_linux-${aarch}.run` and `Atlas-A3-cann-kernels-${version}_linux-${aarch}.run` from [the official download portal](https://www.hiascend.com/developer/download/community/result?module=cann&cann=8.3.RC1), then install them sequentially by following [the CANN official installation documentation](https://www.hiascend.com/document/detail/zh/CANNCommunityEdition/83RC1alpha002/softwareinst/instg/instg_0001.html?Mode=PmIns&OS=Debian&Software=cannToolKit).

- ${version}: CANN version number, e.g., 8.3.RC1
- ${aarch}: CPU architecture type, e.g., aarch64, x86_64

```bash
# ${cann_install_path} denotes the actual CANN installation directory. Remember to source set_env.sh every time you open a new terminal session.
# Option 1: Installed to default path (example for root user)
source /usr/local/Ascend/ascend-toolkit/set_env.sh

# Option 2: Custom installation path
source ${cann_install_path}/ascend-toolkit/set_env.sh
```

### Inference Workflow of Cosmos-Predict2.5-2B on Ascend

Run the following scripts; dependent model weights will be automatically downloaded before inference starts.

```bash
# Skip this step if you are already in the repository root directory
cd cosmos-predict2.5

# Apply NPU adaptation patches
chmod +x npu_adapt.sh
./npu_adapt.sh

# Activate the uv virtual environment
source .venv/bin/activate

# Launch inference for video generation; models will be cached automatically to ~/.cache/huggingface/hub/
python examples/inference.py \
-i assets/base/robot_pouring.json \
-o outputs/base_video2world \
--inference-type=video2world \
--model="2B/post-trained" \
--disable_guardrails
```


For multi-NPU distributed inference, launch the task via torchrun as shown below:
```bash
ASCEND_RT_VISIBLE_DEVICES=0,1,2,3,4,5,6,7 torchrun --nproc_per_node=8 --master_port=12341 examples/inference.py \
-i assets/base/robot_pouring.json \
-o outputs/base_video2world \
--inference-type=video2world \
--model="2B/post-trained" \
--disable_guardrails
```
The entire inference pipeline takes approximately 920 seconds. The output prediction video robot_pouring.mp4 is saved under the ./outputs/base_video2world directory.
